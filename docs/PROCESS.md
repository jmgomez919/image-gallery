# Image Gallery — Process Reflection

**Project:** Responsive Image Gallery
**Author:** Jacob Gomez
**Date:** February 25, 2026

---

## Overview

For this Browser-AI Development Project, I decided to create an interactive and accessible image gallery website to demonstrate the feasibility of prompt-guided code generation in segmented steps. The objective of my project was to interact with my Claude Code in a constructive manner, providing not only prompts but feedback and encouraging the language model to re-check it's responses and code for any errors while developing said project.

---

## Planning

The implimentation of a step-by-step approach to developing the code and files of this project proved to be very helpful and efficient. Dividing the prompt into several stages of generation, refinement, and adjustments, it closed any room for error that could be prevalent amongst large, wordy multi-paragraphed prompts. This approach provided a focused and purposeful means of developing my website and allowing for multiple chances to test the product mid-development to search for potential faults in user interactivity.

---

## Challenges

The most difficult part of this project had to be integrating keyboard navigation and ensure that it was functional for users who may not be able to navigate with a mouse. I developed several prompts to feed into Claude, as well as asking to run several tests and reviews of it's code to check that I could use the directional keys to move around my project. In the end, the testing and debugging proved to be valuable and helped to iron out any other problems I came across.

---

## Decisions

I chose to have a simple layout with pictures next to each other in a grid, while allowing interactive elements such as zoom and highlights help to draw focus to where the user was navigating. I decided to integrate button indicators between the navigational keys in the expanded windows. This helped to show where the user was in the slideshow format of viewing pictures.

---

## What I Learned

I learned that Claude is very efficient when creating a structured, step-by-step timeline of production for projects such as this. I asked to create a responsive image gallery by first creating an itemized list of tasks that should be completed in sequential order, and preferably take between five and ten minutes to complete each seciton. In doing this, not only was it easier on Claude to develop the necessary code and not glitch out, it helped me to understand how the code interacted with eachother and seeing the descriptions provided to assist in making personal edits along the way.

---

## What I Would Do Differently

For the purpose of this project, It looks like everything ran exactly as I hoped it would. I accomplished my objective of crafting an easy-to-use, robust, and simplistic image gallery. More than anything, I was able to incorporate keyboard navigation to make this project ADA accessible. Perhaps in another iteration, I would add a text-to-speech option so that when a "speech" button is selected, the alternative text of an image can be read outloud.

---

## Next Steps

As previously stated, I would work on a few more elements surrounding accessibility to make this project easy for anyone to use.
